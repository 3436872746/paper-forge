# 实验体检 LabCheck

把实验结果贴进去，检查它在统计和可复现性上有没有硬伤。

## 怎么跑

双击 `index.html`。没有构建步骤，不需要装 node，不需要联网。

## 现在能做什么

- **三种数据格式**：`组名: 1, 2, 3`、从 Excel 直接粘的表、`组名,数值` 每行一条。
- **18 条判据**：样本量、多重比较、效应量、安慰剂地板、误差棒、离群点、因果措辞、LLM 的 seed/测试集/消融、不可能的数值。
- **真的算**：Welch t 检验、Holm 校正、Cohen's d、95% 置信区间，全部在浏览器里算，数字不上传。
- **报告**：红黄绿三级，每条给出「为什么是坑 + 怎么改 + 出处」，外加一段能直接贴进 Method 的话。
- **导出**：复制成文本，或下载 `.md`。
- **模型展开**（可选）：填自己的 API Key，把报告改写成段落。默认走通义千问的 OpenAI 兼容接口，不填也能用。

## 文件

| 文件 | 干什么 |
|---|---|
| `index.html` | 页面结构，没有逻辑 |
| `styles.css` | 样式 |
| `rules.js` | 解析 + 统计 + 判据，纯函数，不碰 DOM |
| `app.js` | 界面交互、渲染、导出、模型调用 |

改判据只动 `rules.js` 里的 `KNOWLEDGE` 和 `evaluate()`。加一条判据 = 在 `KNOWLEDGE` 里加一条说明 + 在 `evaluate()` 里加几行判断。
