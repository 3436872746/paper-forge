# 图（Figures）

## 规则

1. **矢量优先（Vector first）**：图（plot）和示意图（diagram）用 PDF/SVG。只有当来源本身
   就是位图（raster）时才用位图；若如此，需在图注中说明。
2. **一图一信息（One message per figure）**。如果图注需要两个"and"，就把这张图拆开。
3. **图注 = 结论（takeaway）**，而不是子图清单。第一句：读者应当得出什么结论。然后是足以
   读懂坐标轴的方法信息。
4. **按 100% 检查**：把页面渲染出来，读最小的刻度标签。如果读不清，说明图对于其内容而言
   太大，而不是在页面上太小。
5. **图幅就是页面预算**：缩小图能换回行数；它同时也会缩小图里的每一个字号。优先砍正文或
   表格间距。
6. **图中的字体**：与论文一致（类 Times）；避免到处加粗；最终尺寸下刻度标签 >= 7 pt。
7. **颜色**：标示量级时使用感知上有序的调色板（perceptually ordered palette）；当用位置能
   表达时，不要把第三个变量编码进色相（hue）。检查灰度打印效果。
8. **不要在图内重复图注已经说明的图例（legend）**；标签重叠是缺陷，不是风格。
9. **从脚本复现**：把绘图脚本放在仓库里，数据放在它旁边。无法重新生成的图只是一张截图
   （screenshot）。
10. **浮动体（Float）**：通栏图由文档类放在页面顶部/底部；对开页上两个连续的通栏图会被读作
    一整块——尽可能用一页正文把它们隔开，但绝不能以牺牲正文可读性为代价。

## 工作流（Workflow）

- 先用占位图（placeholder）打草稿；先写图注，再上数据。
- 按最终宽度生成，不要更宽；在 LaTeX 里缩放会改变有效字号。
- 插入后运行页面审计（`scripts/page_audit.py`）：页数、overfull box、图片所占页面。
- 如果两张图争同一页，判断哪一个论断是核心，把另一张挪开一页。

## 相关 skill

- `schematic-figure`——把概念图/架构图做成矢量 SVG/PDF。
- `dataviz`——图表形式、颜色与注释规则。
- `pdf-figure-vector`——把已有的 PDF 图重绘成矢量图。
