# 图（Figures）

**这一页是干什么的**：它讲论文里的图该怎么画、怎么放、怎么复现。照这十条规则做，图就不会成为审稿人挑毛病的地方。

**什么时候看它**：你在画第一张结果图的时候；你在写图注的时候；你为页数发愁、想缩小图的时候；你把图放进 LaTeX、发现它被挪到页底的时候；你投稿前自查图片质量的时候。

## 1. 一张图只讲一件事

**做什么**：先定这张图要让读者得出什么结论，再决定怎么画。

**规则 2｜一图一信息（one message per figure）**：如果图注需要两个"and"，就把这张图拆开。

**规则 3｜图注 = 结论（takeaway）**：图注不是子图清单。第一句写读者应当得出什么结论，然后写足以读懂坐标轴的方法信息。

**例子**：图注写着"不同批量大小下的吞吐与延迟"，中间有个"and"。这说明它装了两个信息，拆成两张图。新图注第一句改成"吞吐在批量 32 之后不再上升"，第二句再交代硬件和重复次数。

**为什么**：读者先看标题和图注，再决定要不要细看。结论放在第一句，这张图才起作用。

## 2. 能用矢量就用矢量

**做什么**：图的文件格式，按"来源本身是不是位图"来选。

**规则 1｜矢量优先（vector first）**：图（plot）和示意图（diagram）用 PDF/SVG。只有当来源本身就是位图（raster）时才用位图；若如此，需在图注中说明。

**例子**：matplotlib 画完直接存 PDF，不要存 PNG。如果某个监控工具只肯导出 PNG，就在图注末尾写一句"该图为工具导出的截图"。

**为什么**：矢量图（vector，用坐标描述形状的文件）放大不失真。位图（raster，用像素点拼成的文件）放大就出锯齿。

## 3. 图的大小、字号、检查方法

**做什么**：图按最终印刷宽度生成，字号按最终印刷尺寸验收。

**规则 4｜按 100% 检查**：把页面渲染出来，按实际大小读最小的刻度标签。如果读不清，说明图对于其内容而言太大，而不是在页面上太小。

**规则 5｜图幅就是页面预算**：缩小图能换回行数，它同时也会缩小图里的每一个字号。优先砍正文或表格间距。

**规则 6｜图中的字体**：与论文一致（类 Times）；避免到处加粗；最终尺寸下刻度标签 >= 7 pt。

**例子**：先在绘图脚本里量出版心宽度，按这个宽度生成，插进 PDF 时不再缩放。然后把页面打印出来，读最小的刻度数字。读不出或小于 7 pt，就减数据系列、减刻度，而不是把图放大。

**为什么**：在 LaTeX 里缩放图，等于把图里所有字号乘同一个系数。屏幕上看着正常，印出来可能只有 5 pt。

## 4. 颜色、图例、标签

**做什么**：让图形编码只承担它能承担的信息量。

**规则 7｜颜色**：标示量级时使用感知上有序的调色板（perceptually ordered palette，颜色亮度随数值单调变化的配色）。当用位置能表达时，不要把第三个变量编码进色相（hue，颜色的种类）。检查灰度打印效果。

**规则 8｜不要重复图例**：不要在图内放图注已经说明的图例（legend）。标签重叠是缺陷，不是风格。

**例子**：一张折线图用五种颜色区分五种配置，灰度打印后三条线糊成一样。改成不同线型（实线/虚线/点线），再配合位置差异，灰度下仍能分开。图例里与图注重复的那行说明也删掉。

**为什么**：打印稿、投影仪和色觉差异都会让颜色失真。形状和位置更稳。

## 5. 图必须能从脚本重新生成

**做什么**：把"画这张图的脚本 + 数据"当成论文产物的一部分保存。

**规则 9｜从脚本复现**：把绘图脚本放在仓库里，数据放在它旁边。无法重新生成的图只是一张截图（screenshot）。

**例子**：`figures/fig3_throughput.py` 读 `figures/data/fig3.csv`，输出 `figures/fig3.pdf`。审稿人要求换配色，改脚本里一行再跑一次即可，不用重画。

**为什么**：投稿到接收常跨几个月。半年后你不会记得当时的参数，脚本会记得。

## 6. 浮动体（float）放哪里

**做什么**：让自动排版的图落在读者读得顺的位置。

**规则 10**：通栏图由文档类放在页面顶部/底部。对开页上两个连续的通栏图会被读作一整块。尽可能用一页正文把它们隔开，但绝不能以牺牲正文可读性为代价。

**例子**：Fig. 2 和 Fig. 3 都落在第 5–6 页的对开页上，读者会以为是一张双栏大图。在两者之间插一页正文，或者在源文件里把 Fig. 3 往后挪一个浮动位置。

**为什么**：读者判断"这里有几张图"，看的是版面，不是编号。

## 7. 工作流

**做什么**：按固定顺序做图，少返工。

- 先用占位图（placeholder，随便画个方块占住位置）打草稿；先写图注，再上数据。
- 按最终宽度生成，不要更宽；在 LaTeX 里缩放会改变有效字号。
- 插入后运行页面审计（`scripts/page_audit.py`）：页数、overfull box（内容超出栏宽、日志里会报警的行）、图片所占页面。
- 如果两张图争同一页，判断哪一个论断是核心，把另一张挪开一页。

**例子**：写引言时就用占位图排好版，先把总页数压到限制以内。数据跑出来后只替换占位图，版面基本不动。

**为什么**：图注先写，等于先想清楚这张图要证明什么。数据后到也不会跑偏。

## 8. 三个相关 skill

**做什么**：遇到具体画图任务，直接调对应的 skill。

- `schematic-figure`——把概念图/架构图做成矢量 SVG/PDF。
- `dataviz`——图表形式、颜色与注释规则。
- `pdf-figure-vector`——把已有的 PDF 图重绘成矢量图。

**例子**：你要画一张架构图，里面有服务器、队列、GPU 三块。这是示意图，不是数据图，用 `schematic-figure` 生成 SVG。

**为什么**：每个 skill 都带着调好的默认值，比自己从零设参数快。

## 一页速查

- 一张图只说一件事；图注第一句就是结论。
- 图和示意图用 PDF/SVG；位图要在图注里说明。
- 图宽按最终尺寸生成，别在 LaTeX 里缩放。
- 按 100% 读最小的刻度标签；读不清说明内容太多。
- 刻度标签最终 >= 7 pt，字体类 Times，别到处加粗。
- 量级用感知有序配色；能用位置就别用色相。
- 检查灰度打印；标签不许重叠。
- 绘图脚本和数据一起进仓库。
- 通栏图自动放页顶或页底；对开页别让两张连成一块。
- 插入后跑 `scripts/page_audit.py`。
