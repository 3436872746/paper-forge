# 投稿清单（Submission checklist）

## 格式（Format）

- 使用会议**当前**的模板。如果 CFP 更换了模板家族（例如 ACM -> IEEE），就用新的文档类
  重新编译；不要手工移植导言区（preamble）。
- 页数限制：正文页 + 仅含参考文献的页（通常 6+1）。参考文献页必须只包含参考文献。
- 双栏、9-10 pt、US Letter，除非 CFP 另有规定。
- 保持文档类的默认版式：不做全局间距（spacing）覆盖。如果正文溢出，就删字，而不是动模板的
  浮动体间距。
- 额外宏包是正常的（表格、URL、替代文本 alt text）。它们不构成格式违规；更换文档类才是。

## 机械审计（Mechanical audit，打包前运行）

1. 从包的**干净副本**（在别处解压）运行 `pdflatex`。
2. 页数以及参考文献页的位置。
3. overfull box = 0；LaTeX 错误 = 0。
4. 引用编号：首次出现顺序等于 `.bbl` 顺序；每个 `\cite` 键都存在；没有 `??`。
5. 图/表：编号按首次引用顺序；每个浮动体都被引用过。
6. PDF 元数据（metadata）：双盲时标题/作者留空；没有致谢、没有单位、没有邮箱、没有本地路径。
7. 字体已嵌入；页面尺寸正确。
8. 文件清单：主 .tex、参考文献、图；没有来自旧一轮运行的 .aux/.log/.bbl。

## 双盲（Double-blind）

- 自引用（self-citation）用第三人称。
- 提交的 PDF 里不放资助致谢。
- 正文中不放指向自己仓库的链接。
- 作者姓名/单位填进投稿系统，不放进 PDF。

## 作者与利益冲突（摘要阶段）

- **所有**作者的完整姓名、单位、国家、邮箱。
- 与 TPC 成员的利益冲突（COI：导师/学生、N 年内合著、同单位）。
- 缺失作者或 COI 信息会触发 desk-reject（编辑直接拒稿）；摘要截止之后通常不能更改作者。

## AI 生成内容（AI-generated content）

查当前的 CFP。典型政策：LLM 生成的文本/图/代码必须在一个专门的小节里披露（模型、哪些章节、
如何使用）；常规的编辑、翻译和检索通常豁免。要早做决定：披露要占篇幅，并且必须放得进
参考文献页之前。

## 打包与命名（Packaging and naming）

- 产物命名为 `VENUE_KIND_YYYYMMDD[letter]`；绝不用 "final"。
- 保留上一个产物；不要覆盖你可能需要拿来对比的那个 PDF。
- 打包后，再从 zip 构建一次并记录哈希（hash）。
